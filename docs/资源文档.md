# 健腹轮 ym-sports API

抓自米家 App → `xiaomi.abwheel.jfl001`（did `blt.3.1k56n24vg4s01`）。

Base: `https://api.mijia.tech/app`  
Header: `MIOT-REQUEST-MODEL: xiaomi.abwheel.jfl001`  
加密: 与其它 mijia cloud 相同（RC4 / `ssecurity` + `_nonce`）

## 明文请求体（summary / list）

```json
{
  "startTime": 1790438400000,
  "endTime": 1791043199999,
  "type": 1,
  "timezoneOffset": -480,
  "deviceType": "HAW",
  "miId": "<userId>"
}
```

| `type` | 周期 | 时间范围（上海时区） | 趋势序列 |
|--------|------|----------------------|----------|
| `1` | 周 | 周一～周日 | `dailySumList` |
| `2` | 月 | 当月 1 日～月末 | `dailySumList` |
| `3` | 年 | 当年 1/1～12/31 | `monthSumList` |

其它字段：`deviceType: "HAW"`，`timezoneOffset: -480`（UTC+8）。

## summaryAll（累计）

`POST /eco/ym-sports/record/summaryAll`

```json
{
  "timezoneOffset": -480,
  "deviceType": "HAW",
  "miId": "<userId>"
}
```

返回：`count` / `calory` / `duration` / `earliestTime`，以及 `optimumCount` / `optimumCalory` / `optimumDuration`（单次最佳）。

## 接口一览

| Path | 用途 |
|------|------|
| `POST /eco/ym-sports/record/summary` | 周/月/年汇总 + 趋势点 |
| `POST /eco/ym-sports/record/summaryAll` | 全部累计 + 最佳纪录 |
| `POST /eco/ym-sports/record/list` | 单次训练列表（`rows[]`，`hasMore`/`nextKey`） |

### list 单条字段

`id`, `deviceId`, `indexTime`, `duration`, `count`, `calory`, `mode`, `generateTimeStr`, `timezoneOffset`

## Bridge / Desktop

`GET /devices/{did}/abwheel/history` → `list` + `summary`(1/2/3) + `summaryAll`  
桌面端支持周 / 月 / 年 / 全部筛选，趋势图用对应 `dailySumList` / `monthSumList`。

# PC 开机卡操作日志（HiPC）

抓自米家 App → `hipc.plug.m1`（及同类 PC 开机卡）。

Base: `https://api.mijia.tech/app`  
Header: `MIOT-REQUEST-MODEL: <device.model>`  
加密: RC4 / `ssecurity` + `_nonce`

## get_user_device_data（prop 3.6 onoff-log）

`POST /user/get_user_device_data`

```json
{
  "did": "<did>",
  "key": "3.6",
  "type": "prop",
  "time_start": 1710000000,
  "time_end": 1740000000,
  "limit": 50
}
```

`time_start` / `time_end` 为秒级 Unix 时间戳。返回列表项大致为：

```json
{ "did": "<did>", "key": "3.6", "time": 1740000000, "value": [1] }
```

| `value[0]` | 含义 |
|------------|------|
| `1` | 远程开机 |
| `2` | 远程关机 |
| `3` | 远程重启 |
| `4` | 本地开机 |
| `5` | 本地关机 |
| `6` | 本地重启 |

## Bridge / Desktop

`GET /devices/{did}/pcboot/logs?days=180&limit=50` → 云端操作日志  
桌面端 PcBootDetail「操作日志」在 live 模式下拉取并展示。
